# UIUC CS Fundamentals C++ Master

일리노이 대학교(UIUC)의 Accelerated Computer Science Fundamentals 전문 전문가 과정 수강 및 C++20 기반 자료구조/알고리즘 구현 저장소입니다.

## 💻 개발 환경
- **OS**: macOS (Apple Silicon M1)
- **Language**: C++20 Standard
- **IDE**: Visual Studio Code (VS Code)
- **Build System**: CMake (Multi-Project Structure)
- **Compiler**: Apple Clang (with CMake Tools)

## 🛠️ 빌드 및 디버깅 방법 (VS Code)

1. VS Code에서 이 루트 폴더(`jongho-coursera-cpp`)를 엽니다.
2. 하단 상태 표시줄(Status Bar)에서 **CMake 킷(Kit)**을 `Apple Clang`으로 지정합니다.
3. 빌드 변형을 `[CMake: Debug]`로 설정합니다.
4. 실행할 **액티브 타겟**(`[hello_exe]` 등)을 지정합니다.
5. `Shift + F5`를 눌러 즉시 실행하거나, 코드에 중단점을 찍고 디버그 단축키를 눌러 디버깅을 시작합니다.
